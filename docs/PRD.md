# 个人全资产投资管理与复盘系统 (PRD)

| 文档版本     | V1.0                                                     | 文档状态     | 正式发布                |

| **产品定位** | 个人全资产汇总记账、单位净值核算、周期复盘与监控告警系统 | **基准法币** | CNY（支持全局切换 USD） |

---

## 1. 产品概述与目标

### 1.1 背景与痛点

- **市场割裂**：A股、港股、美股、银行理财分散在不同券商/银行 App，无法一站式查看全貌。
- **收益失真**：普通 App 算总资产，中途“加仓/出金”会扭曲真实收益率（缺乏基金级**单位净值化**管理）。
- **复盘缺失**：缺乏将“持仓大盘”、“基准对标（如标普500/沪深300）”和“个人投资心得”整合的周期性复盘工具。

### 1.2 产品目标

1. **多资产聚合**：覆盖 A股、港股、美股、ETF、公募基金、银行理财（含固收/现金类）。
2. **精准核算**：采用“单位份额法”剔除出入金干扰，精确核算真实投资能力。
3. **自动化复盘**：收盘自动抓取行情、核算净值、推送日/月/年复盘报告与异动告警。

---

## 2. 业务流程与系统架构

### 2.1 每日自动化跑批流程（双跑批）

```
[22:00 「A股日终简报」定时触发]
   ├─ 1. 行情爬取: 抓取 A股、港股当日收盘价（美股以最近可得价格估算）
   ├─ 2. 资产结算: 计算预估组合净值 (NAV)，不落正式快照
   └─ 3. 简报推送: 生成 A股视角复盘卡片，推送至 飞书 / 企业微信 / Telegram

[次日 06:00 「终局清算」定时触发（美股已收盘）]
   ├─ 1. 行情爬取: 抓取 美股最终收盘价 + 即期汇率 (USD/CNY, HKD/CNY) 终值
   ├─ 2. 固收计息: 对“预期收益型”理财按日自动计提利息
   ├─ 3. 资产结算: 计算当日总资产、生成 T-1 权威净值快照（每日仅一条权威记录）
   ├─ 4. 统计归因: 计算当日收益、最大回撤、行业分布、基准指数涨跌
   └─ 5. 报告推送: 生成富文本全量复盘卡片，推送至 飞书 / 企业微信 / Telegram
```

> 基准指数（沪深300 / 标普500）经三方免费 API 拉取：AkShare 指数接口 + yfinance `^GSPC`，无需额外付费授权。

## 3. 功能需求详述

### 3.1 资产标的管理模块（Asset Master）

支持多种资产类型及其估值逻辑配置：

| 资产类别          | 支持市场             | 估值模式               | 数据来源 / 计算方式                    |
| :---------------- | :------------------- | :--------------------- | :------------------------------------- |
| **股票 / ETF**    | A股、港股、美股      | **市场价（MARKET）**   | 定时调取行情接口（AkShare / yfinance） |
| **净值型理财**    | 银行 / 私募          | **手动净值（MANUAL）** | 手动录入最新单位净值，支持定期更新     |
| **固收/定期理财** | 银行定期、大额存单   | **按日计息（FIXED）**  | 录入年化利率 $R$，系统按日自动累加价值 |
| **现金管理**      | 活期、余额宝、朝朝宝 | **现金价值（CASH）**   | 净值恒为 1.0，收益合并入总本金         |

---

### 3.2 极简账本与交易录入模块（Ledger）

系统仅用于汇总记录，不在本系统进行撮合交易。

#### 交易类型定义

1. **买入（BUY）**：增加标的持仓，扣减账户内现金（或直接以外部资金买入）。
2. **卖出（SELL）**：减少标的持仓，获得现金。
3. **外部入金（DEPOSIT）**：将外部资金（如工资结余）转入投资系统，**触发增发组合份额**。
4. **外部出金（WITHDRAW）**：提取资金用于消费，**触发缩减组合份额**。
5. **分红派息（DIVIDEND）**：收到现金股息或红股。

_注：系统不记录银证转账等账户间内部资金流转，用户直接录入已完成的交易（BUY 支持以外部资金直接买入）；现金作为 CASH 类资产管理（如 CASH_CNY / CASH_USD / CASH_HKD），净值恒为 1，卖出/分红所得可入账到对应币种现金资产。_

---

### 3.3 净值与绩效核算引擎（Calculation Engine）

#### 核心公式与逻辑

1. **组合总资产（折算为基准币种 CNY）**：
   $$\text{Total Equity} = \sum (\text{持仓数量}_i \times \text{当日单价}_i \times \text{即期汇率}_i) + \text{现金余额}$$

2. **单位净值（Unit NAV）与份额核算**：
   - **初始设立**：第 0 天，设定初始净值 $NAV_0 = 1.0000$，初始总份额 $S_0 = \text{初始总资产}$。
   - **日常波动（无出入金）**：
     $$NAV_t = \frac{\text{当日总资产}_t}{\text{当日总份额}_t}$$
   - **出入金事件发生时（$t$ 日）**：
     - 先计算出入金前的净值：$NAV_{pre} = \frac{\text{出入金前总资产}}{S_{t-1}}$
     - 计算增减份额：$\Delta S = \frac{\text{出入金金额}}{NAV_{pre}}$
     - 更新总份额：$S_t = S_{t-1} + \Delta S$（出金为减）
     - **保证出入金不影响 $NAV$ 走势。**

3. **银行固收理财每日估值**：
   $$\text{当日单价}_t = \text{买入单价} \times \left(1 + \text{年化收益率} \times \frac{\text{持有天数}}{365}\right)$$

### 3.4 周期性复盘系统（Review & Journal）

系统提供自动化报告结合人工记录的闭环：

```
┌─────────────────────────────────────────────────────────────┐
│ 【2026-09-02 投资复盘】                                      │
│ • 单位净值: 1.2584 (+1.12%)     • 累计收益: +25.84%          │
│ • 基准对标: 沪深300 (-0.2%)      • 标普500 (+0.8%)           │
│ • 领涨资产: NVDA (+3.5%)        • 领跌资产: 腾讯控股 (-1.2%) │
├─────────────────────────────────────────────────────────────┤
│ 资产分布: 美股 45% | A股 20% | 银行理财 25% | 现金 10%      │
├─────────────────────────────────────────────────────────────┤
│ [复盘笔记]：                                                │
│ "今日美股科技股财报超预期，港股受宏观数据拖累，理财利息稳定。│
│  计划在美股占比达 50% 时做一次再平衡..."                    │
└─────────────────────────────────────────────────────────────┘
```

#### 周期复盘功能规划

1. **每日收盘简报**：标的涨跌归因、汇率波动影响、净值走势打点。
2. **月度深度复盘**：
   - 胜率与盈亏比分析。
   - 资产大类比例偏离度预警（如：权益类资产超过预设的 70% 警戒线）。
   - 月度最大回撤（MDD）与夏普比率（Sharpe Ratio）。
3. **年度复盘看板**：
   - 全年 NAV 收益曲线 vs 标普500 / 沪深300 收益曲线。
   - 全年最佳单笔操作 / 最大亏损标的复盘。

---

### 3.5 预警与监控推送模块（Alerts）

#### 预警触发规则

- **单日异动预警**：任意自选/持仓标的单日涨跌幅 $\ge \pm 5\%$。
- **回撤风控预警**：组合总资产自历史最高点回撤达 $5\% / 10\%$。
- **定期复盘提醒**：每月最后一个交易日 20:00 推送月度复盘卡片。

#### 推送通道

- 飞书自定义机器人（推荐：支持交互式 Card 消息）
- 企业微信机器人 / Telegram Bot / 邮件

## 4. 数据库设计参考 (核心字段)

```sql
-- 标的资产表
CREATE TABLE dim_assets (
    asset_id VARCHAR(32) PRIMARY KEY,      -- 标的代码，如 AAPL.US, 600519.SH, CMB_WEALTH_01
    asset_name VARCHAR(64) NOT NULL,       -- 资产名称
    asset_class VARCHAR(16) NOT NULL,      -- STOCK, ETF, WEALTH, CASH
    market VARCHAR(8) NOT NULL,            -- US, CN, HK, GLOBAL
    currency VARCHAR(4) NOT NULL,          -- USD, CNY, HKD
    valuation_method VARCHAR(16) NOT NULL, -- MARKET, FIXED, MANUAL
    annual_yield_rate NUMERIC(6,4)         -- 固收年化收益率 (如 0.0280 代表 2.8%)
);

-- 交易流水表
CREATE TABLE fact_transactions (
    trans_id SERIAL PRIMARY KEY,
    asset_id VARCHAR(32) REFERENCES dim_assets(asset_id),
    trans_type VARCHAR(16) NOT NULL,       -- BUY, SELL, DEPOSIT, WITHDRAW, DIVIDEND
    trans_date DATE NOT NULL,
    price NUMERIC(16, 4) NOT NULL,         -- 价格 / 净值
    quantity NUMERIC(16, 4) NOT NULL,      -- 数量 / 份额
    amount_cny NUMERIC(18, 2) NOT NULL,    -- 折合人民币金额
    fee NUMERIC(10, 2) DEFAULT 0,          -- 手续费
    remarks TEXT                           -- 备注
);

-- 组合历史净值表 (用于画图与复盘)
CREATE TABLE fact_portfolio_nav (
    nav_date DATE PRIMARY KEY,
    total_assets_cny NUMERIC(18, 2) NOT NULL, -- 当日总资产 (CNY)
    total_shares NUMERIC(18, 4) NOT NULL,     -- 当日总份额
    unit_nav NUMERIC(12, 4) NOT NULL,         -- 当日单位净值
    daily_return NUMERIC(8, 4),               -- 当日涨跌幅
    benchmark_sp500 NUMERIC(12, 4),           -- 标普500当日净值/点位
    benchmark_csi300 NUMERIC(12, 4),          -- 沪深300当日点位
    review_notes TEXT                         -- 当日复盘日记
);
```
